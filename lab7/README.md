# Lab 7: Iris Dataset Decision Tree Analysis

This repository directory contains the implementation of a decision tree classifier on the Iris dataset.

## Files
- `2547218_LAB7.ipynb`: The Jupyter Notebook containing the full implementation of the lab, including data exploration, preparation, building the model, visualizing it, hyperparameter tuning, and a detailed analysis of the results.

## Workflow Summary
The workflow follows a standard Data Science procedure:
1. **Dataset Exploration:** Loading and inspecting the Iris dataset.
2. **Data Preparation:** Splitting into training and test sets.
3. **Model Building:** Creating a baseline Decision Tree classifier.
4. **Hyperparameter Analysis:** Experimenting with various values for `criterion`, `max_depth`, `min_samples_split`, and `min_samples_leaf` to observe their effects on overfitting and underfitting.
5. **Hyperparameter Tuning:** Using `GridSearchCV` to find the best configuration.

See the notebook for the complete analysis and step-by-step code execution.
