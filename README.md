# Machine Learning Labs

This repository acts as a comprehensive showcase of practical implementations, experiments, and exercises covering various fundamental and advanced concepts in Machine Learning as part of academic practice

## Repository Structure & Branches

To keep everything clean and organized, **each lab has its own dedicated branch**. 

Each branch is named strictly after the corresponding lab number (e.g., `lab3`, `lab4`, `lab10`). To explore the specific code, datasets, and notebooks for a particular lab, you must check out its respective branch.

```bash
# Example: switch to Lab 4
git checkout lab4
```

## Summary of Learnings (Lab 3 to Lab 10)

Across the different labs in this repository, we have covered the following key machine learning topics and algorithms:

* **Lab 3: Simple Linear Regression** 
  * Understanding relationships between two continuous variables.
  * Training a simple linear model to predict outcomes and visualizing the regression line.

* **Lab 4: K-Nearest Neighbors (KNN) Classification** 
  * Implementing the KNN algorithm for classification tasks.
  * Computing distances between data points and evaluating model performance using different values of K.

* **Lab 5: Data Preprocessing and Regression Analysis** 
  * Mastering essential data cleaning techniques, handling missing values, and feature scaling.
  * Encoding categorical variables and extending regression analysis to multiple variables.

* **Lab 6: Logistic Regression and Classification Metrics** 
  * Applying Logistic Regression to solve binary classification problems.
  * In-depth evaluation of models using metrics like accuracy, precision, recall, F1-score, and the confusion matrix.

* **Lab 7: Support Vector Machines (SVM)** 
  * Exploring SVMs for both classification and regression.
  * Experimenting with various kernel functions (linear, polynomial, radial basis function) and tuning hyperparameters.

* **Lab 8: Decision Trees** 
  * Building and evaluating Decision Tree models.
  * Understanding concepts such as information gain, Gini impurity, tree pruning, and visualizing the tree structure.

* **Lab 9: Ensemble Methods** 
  * Utilizing ensemble learning to improve model robustness and reduce variance.
  * Implementing Random Forests, Bagging, and Boosting techniques.

* **Lab 10: Neural Networks & Deep Learning** 
  * Diving into the fundamentals of Deep Learning.
  * Building multi-layer perceptrons, understanding activation functions, and working with forward/backward propagation.

## Getting Started

1. Clone the repository.
2. Check out the branch of the lab you wish to study (e.g., `git checkout lab5`).
3. Navigate to the lab's directory and launch Jupyter Notebook to run the interactive `.ipynb` files.
