# Lab 9: Ensemble Methods

This lab introduces ensemble learning techniques. It covers Random Forests, Bagging, and Boosting methods to improve model performance and reduce variance.

## Contents

This branch specifically contains the workspace and resources for **lab9**.
You will find the following types of files within the `lab9/` directory:
- **Jupyter Notebooks (`.ipynb`)**: Step-by-step interactive code and analysis.
- **Datasets (`.csv`, etc.)**: The data used for training and testing models in this lab.
- **Exported HTML/Scripts**: Any exported versions of the notebooks or helper scripts.

## Getting Started

To explore this lab, navigate to the `lab9/` directory and open the notebooks in Jupyter Lab or Jupyter Notebook.

```bash
cd lab9
jupyter notebook
```
