# Lab 5: Data Preprocessing and Regression Analysis

This lab is centered around data preprocessing techniques and performing multiple regression analysis. It includes handling missing values, feature scaling, encoding categorical variables, and training regression models.

## Contents

This branch specifically contains the workspace and resources for **lab5**.
You will find the following types of files within the `lab5/` directory:
- **Jupyter Notebooks (`.ipynb`)**: Step-by-step interactive code and analysis.
- **Datasets (`.csv`, etc.)**: The data used for training and testing models in this lab.
- **Exported HTML/Scripts**: Any exported versions of the notebooks or helper scripts.

## Getting Started

To explore this lab, navigate to the `lab5/` directory and open the notebooks in Jupyter Lab or Jupyter Notebook.

```bash
cd lab5
jupyter notebook
```
