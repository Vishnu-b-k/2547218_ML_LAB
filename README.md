# Lab 4: K-Nearest Neighbors (KNN) Classification

This lab focuses on the K-Nearest Neighbors (KNN) algorithm. It includes notebooks and datasets to explore classification tasks, compute distances, and evaluate model performance based on different values of K.

## Contents

This branch specifically contains the workspace and resources for **lab4**.
You will find the following types of files within the `lab4/` directory:
- **Jupyter Notebooks (`.ipynb`)**: Step-by-step interactive code and analysis.
- **Datasets (`.csv`, etc.)**: The data used for training and testing models in this lab.
- **Exported HTML/Scripts**: Any exported versions of the notebooks or helper scripts.

## Getting Started

To explore this lab, navigate to the `lab4/` directory and open the notebooks in Jupyter Lab or Jupyter Notebook.

```bash
cd lab4
jupyter notebook
```
