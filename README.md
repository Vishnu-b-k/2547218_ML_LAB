# Lab 3: Simple Linear Regression

This lab covers the implementation of Simple Linear Regression. It includes Jupyter notebooks for data analysis, visualizing relationships, and training a linear regression model to predict outcomes based on the provided dataset.

## Contents

This branch specifically contains the workspace and resources for **lab3**.
You will find the following types of files within the `lab3/` directory:
- **Jupyter Notebooks (`.ipynb`)**: Step-by-step interactive code and analysis.
- **Datasets (`.csv`, etc.)**: The data used for training and testing models in this lab.
- **Exported HTML/Scripts**: Any exported versions of the notebooks or helper scripts.

## Getting Started

To explore this lab, navigate to the `lab3/` directory and open the notebooks in Jupyter Lab or Jupyter Notebook.

```bash
cd lab3
jupyter notebook
```
