# Lab 7: Support Vector Machines (SVM)

This lab covers the Support Vector Machines (SVM) algorithm for classification and regression tasks. It includes experiments with different kernels (linear, polynomial, RBF) and hyperparameter tuning.

## Contents

This branch specifically contains the workspace and resources for **lab7**.
You will find the following types of files within the `lab7/` directory:
- **Jupyter Notebooks (`.ipynb`)**: Step-by-step interactive code and analysis.
- **Datasets (`.csv`, etc.)**: The data used for training and testing models in this lab.
- **Exported HTML/Scripts**: Any exported versions of the notebooks or helper scripts.

## Getting Started

To explore this lab, navigate to the `lab7/` directory and open the notebooks in Jupyter Lab or Jupyter Notebook.

```bash
cd lab7
jupyter notebook
```
