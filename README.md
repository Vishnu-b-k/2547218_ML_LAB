# Lab 8: Decision Trees

This lab is dedicated to building and evaluating Decision Trees. It covers concepts like information gain, Gini impurity, tree pruning, and visualizing the decision tree structure.

## Contents

This branch specifically contains the workspace and resources for **lab8**.
You will find the following types of files within the `lab8/` directory:
- **Jupyter Notebooks (`.ipynb`)**: Step-by-step interactive code and analysis.
- **Datasets (`.csv`, etc.)**: The data used for training and testing models in this lab.
- **Exported HTML/Scripts**: Any exported versions of the notebooks or helper scripts.

## Getting Started

To explore this lab, navigate to the `lab8/` directory and open the notebooks in Jupyter Lab or Jupyter Notebook.

```bash
cd lab8
jupyter notebook
```
