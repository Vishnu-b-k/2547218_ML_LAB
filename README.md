# Lab 10: Neural Networks & Deep Learning

This lab explores the fundamentals of Neural Networks and Deep Learning. It covers building multi-layer perceptrons, activation functions, forward and backward propagation, and using frameworks for deep learning tasks.

## Contents

This branch specifically contains the workspace and resources for **lab10**.
You will find the following types of files within the `lab10/` directory:
- **Jupyter Notebooks (`.ipynb`)**: Step-by-step interactive code and analysis.
- **Datasets (`.csv`, etc.)**: The data used for training and testing models in this lab.
- **Exported HTML/Scripts**: Any exported versions of the notebooks or helper scripts.

## Getting Started

To explore this lab, navigate to the `lab10/` directory and open the notebooks in Jupyter Lab or Jupyter Notebook.

```bash
cd lab10
jupyter notebook
```
