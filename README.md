# Machine Learning Lab Repository

Welcome to the Machine Learning Lab repository! This repository contains various practical assignments, implementations, and experiments covering different concepts in Machine Learning.

## Structure

The repository is organized into directories and branches, each corresponding to a specific lab session:

- **lab1/**: Introduction and basic setup
- **lab3/**: Simple Linear Regression
- **lab4/**: K-Nearest Neighbors (KNN) Classification
- **lab5/**: Data Preprocessing and Regression Analysis
- **lab6/**: Logistic Regression and Classification Metrics
- **lab7/**: Support Vector Machines (SVM)
- **lab8/**: Decision Trees (Available in `lab8` branch)
- **lab9/**: Ensemble Methods (Available in `lab9` branch)
- **lab10/**: Neural Networks & Deep Learning

*Note: For detailed information and clean workspaces for a specific lab, please check out the corresponding branch (e.g., `git checkout lab4`)!*

## Usage

Each lab directory contains Jupyter notebooks (`.ipynb`), Python scripts (`.py`), and any necessary datasets. You can run the notebooks using Jupyter Lab or Jupyter Notebook, or run the scripts directly using Python.
