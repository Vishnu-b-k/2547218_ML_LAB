# Lab 6: Logistic Regression and Classification Metrics

This lab explores Logistic Regression for classification tasks. It also delves into evaluating classification models using various metrics such as accuracy, precision, recall, F1-score, and the confusion matrix.

## Contents

This branch specifically contains the workspace and resources for **lab6**.
You will find the following types of files within the `lab6/` directory:
- **Jupyter Notebooks (`.ipynb`)**: Step-by-step interactive code and analysis.
- **Datasets (`.csv`, etc.)**: The data used for training and testing models in this lab.
- **Exported HTML/Scripts**: Any exported versions of the notebooks or helper scripts.

## Getting Started

To explore this lab, navigate to the `lab6/` directory and open the notebooks in Jupyter Lab or Jupyter Notebook.

```bash
cd lab6
jupyter notebook
```
